# 📸 Simple Photo Editor

A simple and user-friendly photo editor built using HTML, CSS, and Vanilla JavaScript.

This project allows users to upload an image and edit it using basic photo editing features such as brightness, contrast, grayscale, and more.

## 🚀 Features

- Upload images from your device
- Preview the selected image
- Adjust brightness
- Adjust contrast
- Apply grayscale effect
- Rotate images
- Reset edits
- Download the edited image
- Simple and responsive user interface
- Custom theme styling

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
